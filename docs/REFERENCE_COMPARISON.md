## 같은 부분과 다른 부분

| 기준 | 참고 서비스 | 이 과제 |
|---|---|---|
| 연구 질문 | 망막나이 추정과 동일인 양안 차분 | 양안 DR 라벨 차이, 이미지 DR 등급 분류 |
| 데이터 | EyePACS 외에 나이 라벨이 있는 ODIR-5K 등 | 사용자가 제공한 ZIP 및 image/level 라벨 |
| 모델 | 공개 설명상 ConvNeXt 앙상블과 나이 구간 추정 | 동결 MobileNetV3 특징 + 검증 세트로 선택한 로지스틱 분류기 |
| 실제 입력 | 업로드와 예제 사진 | 업로드와 실제 보류 테스트 사례 |
| 설명 이미지 | Grad-CAM | 4×4 영역 가림 민감도. 병변 정답이 아님 |
| 결과 근거 | 양안·정확도·데이터·운영 화면 | 양안 분석, 평가표, 분할/실행/무결성 정보와 다운로드 |
| 재현 | 글에서 재현성을 설명 | 소스, 고정 환경, 사례/보고서/ZIP 생성 파이프라인 제공 |
| GitHub | 해당 서비스의 공개 소스 링크를 찾지 못함 | 과제별 비공개 소스 저장소 2개와 실행 ZIP 릴리스 |

망막나이 모델의 성능과 DR 등급 모델의 성능은 다른 지표이며 직접 비교할 수 없다. 참고 사이트의 `49.1세` 같은 수치, 나이 예측구간, 화질 모델, 분포 밖 입력 검출을 구현했다고 주장하지 않는다. 현재 모델은 나이 및 화질 정답으로 학습하지 않았다.

## 개선 범위

화면은 실제 데이터 탐색과 설명에 초점을 맞춘다. 참고의 짙은 이미지 작업 영역·밝은 결과 영역·명확한 근거 탐색을 적용하되, 두 과제의 질문과 데이터에 맞게 구성한다. 참고의 브랜드·문장·수치·이미지를 결과물로 복제하지 않는다.

코드는 재현 단계에서 누락된 사례 및 뷰어 생성, 실행 당시 기록, 보고서 수치 연결, 설치 환경 고정, 생성 파일 제외 규칙을 보완한다. 완성도는 실행 및 검증 결과로 보고하고, 확인할 수 없는 참고 저장소와의 코드 동등성을 주장하지 않는다.

기존 최종평가를 본 뒤 재학습하거나 후보를 다시 고르지 않았다. `artifacts/v1/frozen-hashes.json`의 모델·백본·평가·분할표 해시로 보존 여부를 검증한다. 실제 테스트 300장은 150명의 양안이며 독립 환자 300명이라는 뜻이 아니다.
