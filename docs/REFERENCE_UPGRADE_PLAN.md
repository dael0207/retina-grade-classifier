# 참고 프로젝트 수준 보완 계획

2026-11-13. 두 과제의 기존 주제와 확정된 v1 모델/최종평가를 유지한다.

## 확인된 기준

- 참고 글: https://ai.intra.avrosoft.co.kr/posts/261113002
- 실행 앱: https://retina-age.intra.avrosoft.co.kr/
- 참고 앱은 EyePACS와 나이 라벨이 있는 ODIR-5K를 사용한다. 현재 제공 자료는 image/level뿐이므로 나이 예측 성능의 동등성을 주장하지 않는다.
- 확인한 참고 페이지에서는 해당 서비스의 공개 저장소 링크를 찾지 못했다. 화면 비교와 코드 품질 검증은 구분한다.

## 실행 및 검증 순서

1. 실제 앱의 화면·상태·기능을 브라우저로 확인하고 차이를 기록한다.
2. 기존 결과의 회귀를 검사한 뒤 재현 결함을 수정한다: 사례/실행기록 생성, 동적 파일 목록, 보고서의 하드코딩된 결과 제거, 오프라인 뷰어 재생성.
3. 설치 버전을 고정하고 소스 저장소에 원본 데이터·모델·개인 환경이 섞이지 않도록 제외 규칙과 데이터 출처 문서를 만든다.
4. 실제 결과에 연결된 사례 체험, 평가 및 데이터 근거 탐색을 보강한다. 수치를 장식으로 만들거나 나이 정답을 만들어내지 않는다.
5. 모델/민감도 코드의 순환 참조 및 타입 경계를 수정하되 기존 모델 파라미터·manifest·최종평가 값을 변경하지 않는다.
6. 테스트·lint·타입 검사, 375/768/1280px 브라우저 및 실제 추론, 보고서 렌더링, 새 ZIP 검증을 수행한다.

## 종료 조건

- 참고 기능 대비표에 구현/차이/미검증 항목을 명시한다.
- 두 과제의 PDF와 실행 가능한 ZIP을 갱신한다.
- 재현 과정이 현재 사례 ID와 숫자에 의존하지 않는다.
- 검증하지 않은 GitHub 저장소 동등성이나 모델 성능을 주장하지 않는다.
- 원격 배포·공개 저장소 게시 없이 로컬에서 검증 가능한 결과를 제공한다.
