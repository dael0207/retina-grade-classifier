Interpretation boundary

확인된 범위

  • 환자 단위 train / validation / test 분리
  • 검증 QWK 우선으로 balanced 후보 선택
  • 선택 뒤 테스트 세트는 한 번만 평가
  • 고정 ImageNet 특징과 선형 분류기 사용
